# ⚡ Legacy Ledger

A full-stack, AI-powered personal wealth and goal management application. Legacy Ledger provides real-time market intelligence, dynamic portfolio tracking, and stoic financial advice powered by Large Language Models (LLMs).

## 🚀 Tech Stack
* **Frontend:** React.js, Framer Motion (Deployed on Vercel)
* **Backend:** Node.js, Express.js (Deployed on Render)
* **Database:** PostgreSQL (Supabase)
* **AI Engine:** Groq API (Dynamic routing / openai/gpt-oss-20b)
* **Market Data:** Yahoo Finance & TwelveData APIs

## 📋 Prerequisites
* Node.js (v22.x recommended)
* PostgreSQL Database
* Groq API Key
